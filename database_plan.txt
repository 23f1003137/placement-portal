User
-----
id (Primary Key)
name
email
password
role (admin / student / company)
is_active
created_at

StudentProfile
--------------
id
user_id (Foreign Key → User.id)
branch
cgpa
year
resume

CompanyProfile
--------------
id
user_id (Foreign Key → User.id)
company_name
hr_contact
website
approval_status (pending / approved / rejected)

PlacementDrive
--------------
id
company_id (Foreign Key → CompanyProfile.id)
job_title
job_description
branch_required
cgpa_required
year_required
application_deadline
status (pending / approved / closed)

Application
-----------
id
student_id (Foreign Key → StudentProfile.id)
drive_id (Foreign Key → PlacementDrive.id)
application_date
status (applied / shortlisted / selected / rejected)
